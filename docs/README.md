# 从零推导英语句子语法

> 写给中文母语者：抛开传统语法术语，用第一性原理和苏格拉底式追问，从"一个句子最少需要什么"出发，一步步推出英语句子的构造，并且处处与中文对照。

核心比喻：**中文像聊天，英语像填表**。中文靠意思驱动，听的人帮你补全；英语靠结构驱动，说的人必须把每一栏填清楚。

## 怎么读

- 每章从"回顾"开始，到"通往下一章"结束，**按顺序读**，后一章用到前一章推出来的零件。
- 每章末尾有练习，答案默认折叠，**先做再点开**。
- 每章都有"反例"小节：这些是中文母语者最容易说错的句子，以及为什么错。
- 第十章是全景：把十章的零件装回一个模型，并给出造句八步法和读长句四步法。
