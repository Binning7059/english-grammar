# 第十章：全景

这一章不再推导新的规则，而是做三件事：

1. 把前九章的发现**组装成一个完整的模型**；
2. 用这个模型**从中文出发，一步一步造出英语**，再**反过来拆解英语长句**；
3. 诚实地说明这个模型**解释不了什么**。

最后，把整套模型浓缩成一张总地图。

## 第 1 步：完整的模型

### 英语句子的表格（最终版）

```
┌──────────────────────────────────────────────────────────────────┐
│ 【句首】（有标记时才用）                                          │
│   话题（This book, I...）、疑问词（What...）、否定词（Never...）     │
│   地点（At the door stood...）、嵌入的条件或时间（If..., When...）  │
├──────────────────────────────────────────────────────────────────┤
│ 【主语栏】必填                                                     │
│   动词的搭档，和动词签人称契约                                      │
│   可以是：名词（贴数量、身份标签）、代词主格（I, he）               │
│           动名词（Swimming）、一整件事（What he said）              │
│           占位符（it, there）                                       │
├──────────────────────────────────────────────────────────────────┤
│ 【动词栏】必填                                                     │
│   情态动词 → have → be（进行）→ be（被动）→ 主要动词               │
│   第一个零件贴时间（远近）标签和人称标签                            │
│   每个零件决定下一个词的形式                                        │
│   没有零件时，提问、否定、强调都请 do                               │
├──────────────────────────────────────────────────────────────────┤
│ 【宾语栏】有没有、有几个，由动词自带的表格决定                      │
│   名词、代词宾格（me, him）、动名词、一整件事（that...）            │
├──────────────────────────────────────────────────────────────────┤
│ 【挂标签的成员】                                                   │
│   介词 + 名词（in the library, to him）                             │
│   嵌入连接词 + 整张表格（because..., when..., if...）               │
├──────────────────────────────────────────────────────────────────┤
│ 【修饰】                                                           │
│   短的形容词放在名词前面；长的修饰放在名词后面（介词短语、who/which）│
│   副词修饰动作；look / taste / feel 后面用形容词                    │
└──────────────────────────────────────────────────────────────────┘

    连接规则：开关的数量 − 1 = 连接词的数量
    重点规则：已知的放前面，新信息和重的成分放句末
```

### 中文的对应模型

```
【话题】+【说明】
    话题：想从哪里说起就从哪里说起，只要和后面有关
    说明：动词、形容词、名词都能直接充当
    词形永远不变；关系靠常识和语境
    该说才说，对方能补全的就省略
```

## 第 2 步：升维总表

这是第一章结尾那张路线图的完整版。当时每一行只是一个问题，现在每一行都已经推导完毕：

| 维度 | 中文的默认方式 | 英语的强制要求 | 章 |
|---|---|---|---|
| 主语 | 可以省略，句首放话题 | 必须填写，放动词的搭档，没有内容就用 *it / there* 占位 | 一 |
| 断言开关 | 动词、形容词、名词都能直接充当 | 必须有一个贴标签的动词，贴不上就请 *be* | 一 |
| 人称契约 | 没有 | 动词跟着主语的人称和数变化 | 一 |
| 谁对谁 | 常识决定，位置、把、被辅助 | 位置或标签必须有一个，常识不参与 | 二 |
| 动词的格局 | 动词后面放什么都行（吃食堂） | 每个动词自带一张表格，栏数固定 | 二 |
| 名词的数量 | 靠量词，需要时才说 | 每个名词都要标明：一个、几个，还是一团 | 三 |
| 名词的身份 | 靠位置和"这、那" | 每个名词都要标明：听话人知不知道是哪个；身份标签只有一个座位（*a / the / my / this* 不能叠用） | 三 |
| 数量词 | "很多""一点"对任何名词通用 | 先问能不能数：*many / few* 配个体，*much / little* 配一团 | 三 |
| "谁的" | 常常省掉（他举起手） | 必须说出来（*his* hand） | 三 |
| 时间 | 靠时间词和语境 | 动词上必须标明远近 | 四 |
| 镜头 | 了、过、着、在，按需使用 | 全景、特写、回看，必须选一个 | 四 |
| 句子的连接 | 意合，逗号就能连接（流水句） | 形合，每个接口需要且只需要一个连接词 | 五 |
| 修饰语的位置 | 一律放在名词前面 | 长的修饰语放在名词后面 | 五 |
| 转述（间接引语） | 里面那件事形式不变（他说他累了） | 主句"远"了，里面的开关也要跟着"远"一步（*said he was tired*） | 五 |
| 连接词与介词 | 一个"因为"，后面接事或接名词都行 | *because* 接表格，*because of* 接名词 | 五 |
| 判断和假设 | 能愿动词可以叠用；假设不改变形式 | 情态动词只能有一个；假设用"远形式" | 六 |
| 词性 | 一个词进入多个位置，形状不变 | 每个位置查身份证，身份不对就变形 | 七 |
| 比较 | 比、更、最，词不变 | 在词上贴标签（*taller*）或请 *more / most* 帮忙，只贴一次 | 七 |
| 副词的位置 | 放在动词前，顺序：时间、地点、方式 | 不能插在动词和宾语中间；句末顺序：方式、地点、时间 | 七 |
| 提问 | 加"吗"，疑问词在原位 | 第一个零件挪到主语前，疑问词移到句首 | 八 |
| 回答 | "对、不对"判断对方的说法 | *yes / no* 表示事实本身 | 八 |
| 重点 | 话题灵活，用"是……的"指着重点 | 新信息放句末，用被动、强调句调整顺序 | 九 |

把这张表压缩成一句话：

> **中文是"意义驱动、听者补全"的语言；英语是"结构驱动、说者交代"的语言。**
> 所谓升维，就是让你说英语时，自动去交代那些在中文里可以不说的维度。

## 第 3 步：造句八步法

从一个中文意思出发，造出英语句子，按下面的顺序走：

| 步骤 | 要问的问题 | 来自哪一章 |
|---|---|---|
| ① 找事件 | 这句话里有几件事？（数中文的动词） | 五 |
| ② 定主线 | 哪件事是主线？其余的事怎样连上去：并排、嵌入，还是拆掉开关？ | 五 |
| ③ 选出发点 | 每件事从谁说起？谁坐主语栏？要不要被动、*there*、*it*？重点放到句末了吗？ | 一、二、九 |
| ④ 查动词表格 | 这个动词有几栏？哪些参与者要挂标签？ | 二 |
| ⑤ 定时间和语气 | 相机放在哪里？用什么镜头？是事实，还是判断、假设？ | 四、六 |
| ⑥ 拼零件、贴标签 | 零件顺序对吗？每个零件后面的词形对吗？人称契约签了吗？ | 一、四、六 |
| ⑦ 处理名词 | 个体还是一团？单数还是复数？听话人知道是哪个吗？身份座位上只放了一个词吗？"谁的"说了吗？ | 三 |
| ⑧ 查身份证 | 每个词的词性对吗？有没有连锁反应？比较标签贴对了吗？副词位置对吗？ | 七 |

最后用第五章的方法**数开关**：开关的数量减一，是否等于连接词的数量？

（如果是问句或否定句，在第⑥步之后检查第八章的规则：第一个零件。）

## 第 4 步：完整走一遍

> 我上周推荐给你的那本书已经被拍成电影了，听说拍得很好。

**建议你先自己用八步法试一遍，再往下看。**

……

**① 找事件**

推荐（我推荐给你，上周）、拍成电影（书，已经）、听说（我）、拍得很好。一共四件事。

**② 定主线**

主线是"书被拍成了电影"。

- "我上周推荐给你的"修饰"书" → 第五章：修饰名词的整张表格放在名词**后面**
- "听说拍得很好"是另一层意思 → 用 *and* 并排连接，"听说"后面嵌入"拍得很好"

**③ 选出发点**

"那本书"是双方都知道的东西，是自然的出发点，坐进主语栏。可是书不会自己拍电影，书是承受者 → 第二章：挂被动的牌子。这同时也符合第九章：已知的书在前，新信息"电影"在句末。

**④ 查动词表格**

- *recommend*：谁推荐、推荐什么、推荐给谁。**注意**：*recommend* 不能像 *give* 那样直接带两个宾语。✗ *I recommended you the book.* → ✓ *I recommended the book **to** you.* 接收的一方必须挂标签 *to*（第二章第 7 步）。
- *make ... into ...*：把某物做成某物。被动后变成 *be made into*。

**⑤ 定时间和语气**

- 推荐：上周，相机在过去，全景 → *recommended*
- 拍成电影：已经，相机在现在，回看 → *has been made*
- 听说：现在得到的消息 → *I hear*（也可以说 *I've heard*）
- 拍得很好：现在的状态 → *it's very well made*

**⑥ 拼零件、贴标签**

*has* + *been* + *made*：*has* 是回看零件，要求后面接过去分词，所以是 *been*；*been* 是被动的 *be*，要求后面接过去分词，所以是 *made*。主语 *the book* 是第三人称单数，所以第一个零件是 *has* 而不是 *have*。

**⑦ 处理名词**

- 书：听话人知道是哪本 → ***the** book*
- 电影：新出现的一部 → ***a** movie*

**⑧ 查身份证**

"拍得很好"：*made* 是过去分词，修饰它的"很好"要用副词 *well*（第七章）→ *well made*

**组装：**

> *The book (that) I recommended to you last week has been made into a movie, and I hear it's very well made.*

**数开关：** *recommended、has、hear、's*，4 个。
**数连接词：** *that*（省略）、*and*、*that*（省略，在 *hear* 后面），3 个。✓

## 第 5 步：翻译一段真实的中文

> 我小时候住在一个小村子里。村子不大，只有几十户人家，一条小河从村前流过。每年夏天，我们几个孩子都会去河里游泳，一玩就是一下午，常常忘了回家吃饭。后来村子里修了公路，很多年轻人都去城里打工了。去年我回去过一次，河已经干了，我认识的人也没剩几个了。要是能回到那个时候就好了。

**同样，建议你先自己翻译一遍。**

……

### 逐句分析

**第一句：我小时候住在一个小村子里。**

- "我小时候"是一件事（我是小孩），英语要用一整张表格嵌进来 → *When I was a child*（第五章）
- "一个小村子"是新出现的 → ***a** small village*（第三章）

**第二句：村子不大，只有几十户人家，一条小河从村前流过。**

- 这是典型的流水句：三件事，只用逗号（第五章）。
- "村子不大"：形容词不能当开关，请 *be*；相机在过去 → *It **wasn't** big*（第一、四章）
- "只有几十户人家"：作为对"不大"的补充说明，可以不用独立的开关，用破折号接在后面：*just a few dozen families*。它只是一个名词短语，没有自己的主语和开关，不算一张表格，所以数开关时也不算它（第五章第 8 步）。"户"是量词，英语的 *family* 本身可数，不需要量词（第三章）。
- "一条小河从村前流过"：小河是**新出现**的东西。如果写成 *A little river ran past it*，新信息就放在了句首。更好的做法是用 *there* 占位，把它让到后面（第三、九章）→ *and **there was** a little river running past the front of it*

**第三句：每年夏天，我们几个孩子都会去河里游泳，一玩就是一下午，常常忘了回家吃饭。**

- "会"在这里表示过去的习惯。第六章第 5 步：*will* 的远形式 *would* 可以表示过去的习惯，中文用的也正好是"会" → *would go swimming*
- "去河里游泳"是连动句 → *go swimming*（第五章）
- "河"已经提过了 → ***the** river*（第三章）
- "一玩就是一下午"没有主语 → 补上 *we*（第一章）
- "忘了回家吃饭"：回家是还没发生的事 → *forgot **to** go home*（第五章第 7 步：*to* 朝向还没发生的事）
- 这一句太长，拆成两句（第九章第 6 步）

**第四句：后来村子里修了公路，很多年轻人都去城里打工了。**

- "修了公路"：谁修的？中文没说，也不需要说。英语的主语栏必须填 → 用被动，*a road **was built***（第二、九章）
- "去城里打工"：连动句，"打工"是目的 → *left **to work** in the city*（第五章）
- 两件事用 *and* 连接

**第五句：去年我回去过一次，河已经干了，我认识的人也没剩几个了。**

- "回去过一次"：中文用了"过"，但有"去年"把相机固定在过去 → *I **went** back once last year*，**不能**说 ✗ *I have been back last year*（第四章第 5 步）
- "河已经干了"：相机在去年那个时间点，回看更早发生的事 → *The river **had dried up***（第四章：过去的回看）
- "我认识的人"：修饰语放在名词后面 → *the people I knew*（第五章）
- "没剩几个了"：*hardly* 本身带有否定的意思（"几乎不"），*hardly any* 就是"几乎没有"。和 *not ... any* 一样，带否定意思的词要放在 *any* 前面（第八章第 5 步）

**第六句：要是能回到那个时候就好了。**

- 和现在的事实相反的愿望 → *I wish I **could** go back*（第六章：远形式）

### 完整的译文

> *When I was a child, I lived in a small village. It wasn't big — just a few dozen families — and there was a little river running past the front of it. Every summer, a few of us kids would go swimming in the river. We would spend whole afternoons there and often forgot to go home for dinner. Later, a road was built through the village, and many of the young people left to work in the city. I went back once last year. The river had dried up, and hardly any of the people I knew were still there. I wish I could go back to those days.*

注意几个变化：中文的六句话，英语变成了八句；中文没说的主语、时间、单复数、"一个还是那个"，英语全都交代了；中文的"都""就""过""了"，在英语里各有去处，但没有一个是逐字对应的。

## 第 5 步（续）：再译一段，看看这一次用到哪些章

> 我的邻居王阿姨今年七十岁了，比我妈妈还大五岁。她说她年轻的时候在一家工厂工作，每天都得很早起床。现在她退休了，每天早上都去公园打太极拳，身体比以前好多了。她常常对我说，如果当年她知道锻炼这么重要，她会早点开始的。

建议你先自己翻一遍，再看分析。

……

**逐句分析**

**第一句：我的邻居王阿姨今年七十岁了，比我妈妈还大五岁。**

- "我的邻居王阿姨"：王阿姨是世界上只此一位的，名字已经说明了是哪一个，"我的邻居"只是补充 → 加逗号的补充（第五章）：*My neighbor, Auntie Wang,*
- "七十岁"：形容词性的说法，请 *be*（第一章）→ *is seventy*。"今年"是时间，放句末。
- "比我妈妈还大五岁"：比较，"比"后面的对象放在后面；差距"五岁"放在比较级前面（第七章）→ *five years older than my mother*

**第二句：她说她年轻的时候在一家工厂工作，每天都得很早起床。**

- "她说"：宾语栏里是一整件事，用 *that*（第五章）。"说"是现在的事（她现在还这么说），所以 *says*。
- "年轻的时候"：时间背景，嵌入 → *when she was young*（过去的事，*was*）
- "在一家工厂工作"：新出现的工厂 → *a factory*（第三章）；*in a factory* 或 *at a factory*
- "每天都得很早起床"：*得* = *had to*（*must* 没有过去形式，第六章）；"每天"放句末（第七章）。

**第三句：现在她退休了，每天早上都去公园打太极拳，身体比以前好多了。**

- "退休了"："了"表示和现在相关 → 现在完成时 *has retired*（第四章）
- "每天早上都去公园打太极拳"：连动句，"打太极拳"是目的（第五章）→ *goes to the park to practice tai chi*；"每天早上"放到前面当时间背景（第七章：时间可以提到句首）
- "身体比以前好多了"：*in much better health than before* 或 *her health is much better than before*。"好多了"用 *much* + 比较级，不能用 *very*（第七章）

**第四句：她常常对我说，如果当年她知道锻炼这么重要，她会早点开始的。**

- "常常"：频度副词放在第一个零件后面、主要动词前面（第七章）→ *often tells me*
- "对我说"：*tell* 的听话人紧跟在动词后面（第二章、第五章）→ *tells me that ...*
- "如果当年她知道……她会早点开始"：和过去事实相反，远两层（第六章）→ *if she had known ..., she would have started earlier*
- "锻炼这么重要"：嵌在 *known* 的宾语栏里，是一个被嵌入的"how + 形容词"问句，不倒装（第五章、第八章）→ *how important exercise was*；因为 *had known* 是"远"，里面的 *is* 跟着变成 *was*（第五章：转述时的一步）
- "锻炼"：说的是一整类，不可数，不加冠词（第三章）→ *exercise*（✗ *the exercise*）

**完整译文：**

> *My neighbor, Auntie Wang, is seventy this year, five years older than my mother. She says that when she was young, she worked in a factory and had to get up very early every day. Now she has retired, and every morning she goes to the park to practice tai chi. She is in much better health than before. She often tells me that if she had known how important exercise was, she would have started earlier.*

对比第一段，这一次几乎每一章都用到了。真实的翻译，从来不是"用一章的知识翻译一句话"，而是**同时用到所有的维度**。

## 第 6 步：反过来用——拆解英语长句

这套模型不仅能造句，还能**读句子**。遇到看不懂的英语长句，把八步法倒过来用：

1. **找开关**：找出所有贴了标签的动词。
2. **找连接词**：找出 *that、which、who、if、because、and* 等。检查：连接词是否比开关少一个？
3. **找主线**：哪个开关不在任何连接词的管辖之下？它就是主句的开关。
4. **一层一层地剥开**：每个连接词引出的表格，嵌在了哪里？

**试一试：**

> *The report that the committee published last week, which many experts had been waiting for, suggests that the problems the city faces could have been avoided if action had been taken earlier.*

……

**第 1 步，找开关：** *published*、*had* (been waiting)、*suggests*、*faces*、*could* (have been avoided)、*had* (been taken)。一共 6 个。

**第 2 步，找连接词：** *that*、*which*、*that*、（省略的 *that*，在 *problems* 和 *the city* 之间）、*if*。一共 5 个。✓

**第 3 步，找主线：** *suggests*。它的主语是 *The report*。

**第 4 步，一层一层剥开：**

```
The report
    [that the committee published last week]           ← 修饰 report
    [which many experts had been waiting for]          ← 也修饰 report（空位在 for 后面）
suggests
    [that the problems                                 ← suggests 的宾语
          [(that) the city faces]                      ← 修饰 problems（空位在 faces 后面）
     could have been avoided                           ← 对过去的判断（第六章）+ 被动
          [if action had been taken earlier]]          ← 和过去事实相反的条件（第六章）
```

**主干只有一句话：** *The report suggests that the problems could have been avoided.*（这份报告指出，这些问题本来是可以避免的。）

其余的部分，都是挂在这根主干上的枝叶。

**中文译文：** 委员会上周发布了一份报告，许多专家对此期待已久。报告指出，如果早点采取行动，这座城市面临的问题本来是可以避免的。

注意中文译文的做法正好相反：把英语后置的修饰语提到前面，或者拆成独立的句子，又变回了中文的流水结构。

### 再拆一句

> *The more the company expanded, the harder it became for the founder, who had built it from nothing, to make decisions without consulting the people who had joined later.*

建议你先自己拆，再看分析。

……

**第 1 步，找开关：** *expanded*、*became*、*had built*、*had joined*。一共 4 个。（*to make* 和 *consulting* 不贴标签，不是开关。）

**第 2 步，找连接词：** *the more ..., the harder ...*（一对，算一个接口）、*who had built ...*、*who had joined ...*。一共 3 个。✓（4 − 1 = 3）

**第 3 步，找主线：** *became*。主语是 *it*（第一章的占位符），真正的内容是后面的 *to make decisions ...*（第五章：用 *it* 占位，把长的内容挪到后面）。

**第 4 步，一层一层剥开：**

```
The more the company expanded,                       ← "越……"，第一半（嵌入）
the harder it became                                 ← "越……"，主句；it 是占位符
        for the founder                              ← to make 的"做事的人"
              [, who had built it from nothing,]     ← 加逗号：补充信息，创始人只有一位
        to make decisions                            ← it 所指的内容（拆掉开关的动词）
        without consulting                           ← 介词 + -ing（第七章）
              the people
                  [who had joined later]             ← 不加逗号：区分是哪些人
```

**主干：** *It became harder for the founder to make decisions.*（做出决定对创始人来说变得更难了。）

**中文译文：** 公司越扩张，那位从零开始创办公司的创始人，就越难在不征求后来加入的人的意见的情况下做出决定。

这一句用到了：比较（第七章）、占位 *it*（第一章）、拆掉开关的动词（第五章）、加逗号和不加逗号的修饰语（第五章）、介词后面接 *-ing*（第七章）。

## 第 7 步：这个模型解释不了什么

一个从第一性原理推出来的模型，必须诚实地说出自己的边界。

**问题：** 回顾前九章，有哪些地方我们说过"这个要一个一个地记"？

……

| 模型解释不了的 | 例子 | 出现在哪一章 |
|---|---|---|
| 哪个名词可数，哪个不可数 | *suggestion* 可数，*advice* 不可数 | 三 |
| 哪个动词有哪种表格 | *arrive* 要加 *in*，*reach* 不用 | 二 |
| 哪些动词可以"自己发生" | *The door opened* 可以，*The book published* 不行 | 二 |
| 动词后面接 *to* 还是 *-ing* | 大致有规律，但有例外 | 五 |
| 介词的边界用法 | 大方向可以推（*at* 点、*on* 面、*in* 容器），边界要记：*in the car* / *on the bus*，*at night* / *in the morning* | 二 |
| 冠词的惯例 | *play the piano* / *play football*，*in hospital*（英）/ *in the hospital*（美） | 三 |
| 哪些动词可以不带 *to*（*let me go*、*saw him leave*） | 词汇习惯 | 五 |
| *say / tell / explain* 等动词的表格 | *explain it to me*（✗ *explain me it*） | 二、五 |
| 动词和名词的搭配 | *make* a decision，*do* homework，*take* a photo（中文都可以说"做""拍"） | 新 |
| 习语和固定说法 | *First come, first served.* | 一 |
| 英式和美式的差别 | *Did you eat yet?* / *Have you eaten yet?* | 四、六 |
| 正式和随意的差别 | *whom* / *who*，*If I were* / *If I was* | 二、六 |

**这些东西有一个共同点：它们属于词汇，而不属于结构。**

> **语法模型告诉你：哪里有格子，每个格子要求什么样的东西。**
> **词汇告诉你：具体要往格子里填哪个词。**

这个模型并不能取代词典，但它能告诉你**该去词典里查什么**：这个名词是 C 还是 U？这个动词带不带宾语？后面接 *to* 还是 *-ing*？跟哪个介词搭配？

还要说明一点：这套模型是为中文母语者学习英语而设计的，用的是比喻（表格、开关、标签、镜头）。语言学家描述英语时会用另一套术语，有些地方的解释也更复杂。凡是我们说"这是一种强烈的倾向"的地方，它就不是一条没有例外的定律。

## 第 8 步：总地图

```
═══════════════════════════════════════════════════════════════════
                  英语句子的第一性原理 · 总地图
═══════════════════════════════════════════════════════════════════

前提：语言 = 把我脑子里的事搬进你脑子里

中文：意义驱动，听者补全    话题 + 说明，词形不变，该说才说
英语：结构驱动，说者交代    表格必填，标签必贴，关系必写

───────────────────────────────────────────────────────────────────
九条定律
───────────────────────────────────────────────────────────────────
一  主语与开关  主语栏必填（没有就用 it / there 占位）
               主语是动词的搭档，不是话题
               一个断言一个开关；动词贴时间和人称标签
               贴不上标签就请 be；标签只贴一次

二  角色        每个参与者的角色，要么由位置说明，要么由标签说明
               常识不参与；每个动词自带一张表格
               in / on / at：点、面、容器

三  名词        每个名词贴两张标签：
               个体还是一团（单数 / 复数）；听话人知不知道是哪个
               可数名词的单数形式，绝不能光着出现
               身份座位只有一个（a / the / my / this 不能叠用）
               先问能不能数：many / few 配个体，much / little 配一团

四  时间        相机位置（现在 / 过去 / 将来）× 镜头（全景 / 特写 / 回看）
               零件按顺序拼装，每个零件决定下一个词的形式
               现在完成时属于现在

五  连接        开关的数量 − 1 = 连接词的数量
               并排连接、嵌入连接、拆掉开关
               长的修饰语放在名词后面
               因为 + 事 = because；因为 + 名词 = because of
               主句"远"了，里面的开关跟着"远"一步（He said he was…）
               修饰语不加逗号：区分是哪个；加逗号：补充信息

六  事实之外    情态动词排在第一位，只能有一个
               远形式表示三种远：时间、现实、礼貌
               虚拟 = 远一层（和现在相反）或远两层（和过去相反）
               去掉 if，把 had / were / should 挪到主语前

七  身份证      每个栏目查身份证；身份不对就变形
               一个词换身份，周围的词连锁反应
               -ing 描述引起感觉的东西，-ed 描述产生感觉的人
               比较标签只贴一次（taller / more beautiful）
               副词不插在动词和宾语中间；句末：方式、地点、时间

八  提问与否定  第一个零件负责一切：挪到前面就是提问，后加 not 就是否定
               没有零件就请 do；yes / no 看事实，不看问法
               疑问词对应空位，介词跟着空位走（What are you looking at?）
               So / Neither + 第一个零件 + 主语

九  重心        已知的放前面，新信息和重的成分放句末
               用被动、there、it 强调句、what 强调句调整顺序
               一段话里，每一句从上一句的已知信息说起
               中文的"是……的"不是 be，直接说或用强调句

───────────────────────────────────────────────────────────────────
造句八步法
───────────────────────────────────────────────────────────────────
① 找事件  ② 定主线  ③ 选出发点  ④ 查动词表格
⑤ 定时间和语气  ⑥ 拼零件、贴标签  ⑦ 处理名词  ⑧ 查身份证
→ 最后数开关
```

## 综合练习（先自己做，再看答案）

**一、用八步法翻译**

1. 他去年开始学钢琴，现在已经能弹好几首曲子了。
2. 要是你昨天告诉我会议改时间了，我就不会迟到了。
3. 我们班有个同学英语说得特别好，是在美国长大的。

**二、用读句四步法拆解，找出主干，并翻译成中文**

4. *What surprised me most was that the old man who lived next door, whom I had never seen leave his house, had once been a famous pilot.*

---

<details>
<summary><b>👉 做完了再点开：查看答案</b></summary>


**1.** *He started learning the piano last year, and he can already play several pieces.*

- "开始学"：*start* 后面接 *-ing* 或 *to* 都可以（第五章）
- "去年"把相机固定在过去 → *started*（第四章）
- "能弹"→ *can*，后面接原形 *play*（第六章）
- "好几首曲子"：*pieces*，可数复数（第三章）。注意 *the piano*：乐器前一般加 *the*，这属于词汇层面的惯例（第 7 步）。
- 开关：*started、can*，2 个；连接词：*and*，1 个 ✓

**2.** *If you had told me yesterday that the meeting time had been changed, I wouldn't have been late.*

- 和过去事实相反 → 远上加远：*had told*、*wouldn't have been*（第六章）
- "会议改时间了"：谁改的不重要，会议是出发点 → 被动；而且这件事发生在"告诉"之前 → 过去的回看：*had been changed*（第二、四章）
- "告诉我"的内容是一整件事，坐进宾语栏 → *that ...*（第五章）
- 开关：*had told、had been changed、wouldn't*，3 个；连接词：*if、that*，2 个 ✓

**3.** *There's a student in our class who speaks English really well. He grew up in America.*

- 这位同学是新出现的人 → 用 *there* 占位，让他落到句末（第三、九章）
- "说得特别好"修饰动作 → 副词 *well*，不是 *good*（第七章）
- "是在美国长大的"：中文的"是……的"不能逐字翻译成 ✗ *He is grew up*，直接说 *He grew up in America*（第九章）
- 中文的一句话，英语分成两句更自然

**4.** 拆解：

- 开关：*surprised、was、lived、had (never seen)、had (once been)*，5 个（*leave* 不贴标签，是 *see* 后面拆掉开关、连 *to* 也不带的原形，见第五章第 7 步的反例，不算开关）
- 连接词：*what、that、who、whom*，4 个 ✓
- 主线：*was*。主语是 *What surprised me most*（第九章：*what* 强调句），*was* 后面是 *that ...* 这一整件事
- 主干：*What surprised me most was that the old man had once been a famous pilot.*

```
What surprised me most                          ← 主语（what 强调句）
was
    that the old man                            ← 重点放在句末
           [who lived next door]                ← 修饰 old man
           [whom I had never seen leave his house]  ← 修饰 old man（空位在 seen 后面）
         had once been a famous pilot           ← 过去的回看（第四章）
```

中文译文：**最让我吃惊的是，住在隔壁的那位老人——我从来没见他出过家门——竟然曾经是一位著名的飞行员。**

## 结语

十章走下来，我们没有背过一条规则。每一条规则，都是从"语言是把我脑子里的事搬进你脑子里"这一个前提出发，在中文和英语两面镜子之间推出来的。

所谓"认知维度升级"，并不是让你忘掉中文，而是让你看清楚：中文在哪些地方选择了信任听话的人，而英语在同样的地方选择了把一切交代清楚。当你说英语时，脑子里能自动亮起那几盏灯——主语栏填了吗？开关贴标签了吗？这个名词是哪一个？相机放在哪里？——升维就完成了。

接下来最有效的练习方法，是**每天用八步法翻译两三句中文，再用读句四步法拆解一两个英语长句**。

如果某一步读完还卡着，最好的办法是回到那一章、那一步的问题，先合上答案自己回答一遍，再往下读。每一条规则都是被一个问题逼出来的；只要那个问题你能自己回答，规则就不需要背。
