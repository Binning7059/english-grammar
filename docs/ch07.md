# 第七章：词的身份证

## 第 0 步：回顾

前六章建起来的英语句子表格是这样的：

```
【主语栏】    【动词栏】                 【宾语栏】     【挂标签的成员】
 名词贴两张    情态动词 → have → be →     名词贴两张      to / with / in ...
 标签          be → 主要动词              标签
              （标签贴在第一个零件上）
```

我们一直在讨论"栏目"：主语栏、动词栏（开关就是它的第一个零件）、宾语栏。第一章的两个错句其实早就埋下了伏笔：✗ *I very happy* 是因为 *happy* 贴不上标签，进不了动词栏；✗ *I am agree* 是因为 *agree* 本身能进动词栏，却被当成了 *happy* 那样的词。可见英语的词并不是随便哪个栏目都能进的。但有一个问题始终没有正面回答：

> **什么样的词，才有资格进入某一个栏目？中文的一个词为什么可以随便进入不同的栏目，而英语的词一换栏目就要换形状？**

---

## 第 1 步：问题出现了

看下面几句话里的"学习"：

- 我**学习**英语。
- **学习**很重要。
- 这是一种好的**学习**方法。
- 他**学习**很认真。

"学习"这两个字，形状一点都没变，可它在每句话里的作用各不相同。

翻成英语：

- *I **study** English.*
- ***Studying** is important.*
- *This is a good **study** method.* / *a good way **of studying***
- *He **studies** hard.*

再看"快乐"：

- 我很**快乐**。→ *I am **happy**.*
- **快乐**很重要。→ ***Happiness** is important.*
- 他们**快乐**地生活着。→ *They live **happily**.*

**问题：** 中文的"快乐"一个形状走遍天下，英语却变出了 *happy、happiness、happily* 三个形状。英语为什么要这么麻烦？

先别急着回答。我们先回到表格，看看每个栏目到底需要什么样的词。

---

## 第 2 步：从栏目推出词的种类

**问题：** 前六章里，我们给不同的词贴过不同的标签。回忆一下，哪些词能贴哪些标签？

……

| 能贴的标签 | 来自哪一章 | 这种词能进入的位置 |
|---|---|---|
| 数量（*-s*）、身份（*a / the*） | 第三章 | 主语栏、宾语栏、介词后面 |
| 时间（*-ed*）、人称（*-s*） | 第一、四章 | 动词栏 |
| 比较（*-er / -est*、*more / most*） | 本章第 9 步 | 修饰名词，或放在 *be* 后面 |
| 几乎不贴标签，但位置有讲究 | 本章第 10 步 | 修饰动词、修饰形容词、修饰整句 |

这四种词，传统语法分别叫作**名词、动词、形容词、副词**。

> **一个词属于哪一类，取决于它能贴哪些标签、能进入哪些栏目。** 这就是它的身份证。

用一个简单的方法就能测试一个词的身份：

- 能说 *a ___* 或 *the ___*，能加 *-s* 变复数吗？→ 名词（*a decision*、*two decisions*）
- 能加 *-ed* 变过去、加 *-s* 配合 *he* 吗？→ 动词（*decided*、*he decides*）
- 能放进 *a very ___ book* 吗？→ 形容词（*a very good book*）
- 能放在动词后面，说明"怎么做"吗？→ 副词（*run quickly*）

### 现在来回答第 1 步的问题

*happy* 是形容词，它的身份证上写着"可以修饰名词，可以放在 *be* 后面"。它**没有资格**坐进主语栏，因为主语栏只收名词。

想让"快乐"坐进主语栏，就必须先给它换一张名词的身份证：*happy* → *happiness*。想让它修饰动词 *live*，就要换一张副词的身份证：*happy* → *happily*。

> **英语的每个栏目都要查身份证。词要进入一个栏目，就必须持有那个栏目要求的身份证；身份证不对，就要先变形。**

---

## 第 3 步：中文为什么不需要变形？

**问题：** 中文的"安静"在下面三句话里做了不同的事。中文有没有用什么手段来标明这种区别？

- 请**安静**。
- 一个**安静**的房间。
- 他**安静**地坐着。

……

"安静"这个词本身一点都没变。但请注意它旁边的字：

- 安静**的**房间（修饰名词，用"的"）
- 安静**地**坐着（修饰动词，用"地"）

中文其实**也在标记**，只是标记的方式完全不同：

> **中文不改变词本身，而是在词的旁边加一个小小的连接字（的、地、得）。英语直接改变词的形状。**

而且中文的这些连接字常常可以省略（"安静房间"也能说），口语里三个字的读音都是 *de*，连书写上的区别都是二十世纪才规范起来的。

**中文里一个词可以进入多个栏目，这是常态。** 更多例子：

| 中文（形状不变） | 英语（换身份证） |
|---|---|
| 我们**讨论**一下。／这次**讨论**很有用。 | Let's **discuss** it. / The **discussion** was useful. |
| 经济在**发展**。／经济的**发展** | The economy is **developing**. / the **development** of the economy |
| 这很**重要**。／它的**重要**性 | This is **important**. / its **importance** |
| 他很**成功**。／他的**成功** | He is **successful**. / his **success** |
| 交通很**方便**。／为了**方便**起见 | Transport is **convenient**. / for **convenience** |
| 我很**担心**。／我**担心**你。 | I'm **worried**. / I **worry** about you. |
| 他**死**了。／**死**的人／**死**亡 | He **died**. / the **dead** man / **death** |

---

## 第 4 步：英语换身份证的工具——后缀

英语主要靠在词的末尾加一段东西（传统语法叫**后缀**）来换身份证：

| 换成的身份 | 常见后缀 | 例子 |
|---|---|---|
| 动词 → 名词 | *-tion / -sion* | decide → deci**sion**，discuss → discus**sion** |
| | *-ment* | develop → develop**ment**，agree → agree**ment** |
| | *-al* | arrive → arriv**al**，refuse → refus**al** |
| | *-ance / -ence* | appear → appear**ance**，exist → exist**ence** |
| | *-er / -or*（做这件事的人） | teach → teach**er**，act → act**or** |
| 形容词 → 名词 | *-ness* | happy → happi**ness**，kind → kind**ness** |
| | *-ity* | possible → possibil**ity**，real → real**ity** |
| | *-ce* | important → importan**ce**，different → differen**ce** |
| 名词 / 动词 → 形容词 | *-ful / -less* | success → success**ful**，care → care**less** |
| | *-ous* | danger → danger**ous** |
| | *-able / -ible* | accept → accept**able** |
| | *-ive* | act → act**ive** |
| | *-y* | rain → rain**y** |
| 形容词 → 副词 | *-ly* | quick → quick**ly**，careful → careful**ly** |
| 名词 / 形容词 → 动词 | *-ize / -ify / -en* | modern → modern**ize**，simple → simpl**ify**，wide → wid**en** |

**这张表的真正用处是阅读。** 遇到一个不认识的词，比如 *inevitability*，即使不知道意思，看到 *-ity* 就知道它是名词，可以放在主语栏或宾语栏里。这样就能先把句子的结构看清楚，再去查词义。

中文其实也有少量类似的成分，比如"可能"变成"可能**性**"，"现代"变成"现代**化**"，"科学"变成"科学**家**"。但在中文里，这些成分数量少，而且大多数时候不是必需的。

## 第 5 步：动词坐进主语栏或宾语栏

> 学英语很重要。

照着中文翻译：✗ *Learn English is important.*

**问题：** 用第五章的方法数开关，这句话出了什么问题？

……

*learn* 和 *is* 是两个开关，中间却没有连接词。而且 *learn* 是动词，没有资格坐进主语栏。

第五章说过，英语可以"拆掉开关"。*-ing* 形式正好有两个作用：

1. 拆掉开关，*learn* 不再贴时间和人称标签；
2. 同时让它拿到一张**名词的身份证**，可以坐进主语栏、宾语栏，或者放在介词后面。

> ***Learning** English is important.*

这种 *-ing* 形式，传统语法叫**动名词**。

### 同一个 -ing，三种身份

你也许注意到了，*-ing* 我们已经见过好几次：

| 出现的位置 | 例子 | 它在做什么 | 来自哪一章 |
|---|---|---|---|
| 跟在 *be* 后面 | She is **eating**. | 特写镜头的一部分 | 第四章 |
| 坐在主语栏、宾语栏、介词后面 | **Eating** too fast is bad. | 当名词用 | 本章 |
| 跟在名词后面 | the girl **eating** an apple | 修饰名词 | 第五章 |

这三个 *eating* 长得一模一样，都不贴标签（都是第五章说的"拆掉开关"的动词），可它们的作用完全不同。是什么决定了它的作用？

……

**是它所在的栏目。** 这恰好说明了本章的主题：在英语里，一个词能做什么，要看它进了哪个栏目、拿着什么身份证。*-ing* 这个形式就像一张"通用身份证"，进了名词的位置就当名词用，跟在名词后面就当修饰语用。

### 介词后面只收名词

第二章说过，介词是挂在成员身上的标签。介词后面挂的必须是一个名词性的东西。所以，动词放在介词后面时，必须先变成 *-ing*：

| 错句 | 正确说法 |
|---|---|
| ✗ I'm good at **swim**. | I'm good at **swimming**. |
| ✗ Thank you for **help** me. | Thank you for **helping** me. |
| ✗ He left without **say** goodbye. | He left without **saying** goodbye. |

### 反例：*to* 后面有时接原形，有时接 *-ing*

- *I want **to see** you.*
- *I look forward **to seeing** you.*

两句话里都是 *to*，为什么一个接原形，一个接 *-ing*？

……

因为这两个 *to* **身份不同**：

- *want to see* 里的 *to*，是第五章那个"拆掉开关"的标记，后面接原形。
- *look forward to seeing* 里的 *to*，是第二章那个"挂在成员身上的标签"，也就是介词，后面要接名词性的东西。

**怎样分辨？** 试着在 *to* 后面放一个普通名词：

- *I look forward to **the party**.* ✓ → 这个 *to* 是介词，所以接 *-ing*
- ✗ *I want to **the party**.* → 这个 *to* 不是介词，所以接原形

用这个方法，还能判断出下面这些 *to* 都是介词：

- *I'm used **to getting** up early.*（我习惯了早起）
- *When it comes **to cooking**, he's the best.*（说到做饭，他是最好的）
- *I object **to being** treated like this.*（我反对被这样对待）

## 第 6 步：*-ing* 和 *-ed*——谁引起了感觉？

> 这部电影很无聊。
> 我很无聊。

中文用的是同一个词"无聊"。英语：

- *The film is **boring**.*
- *I am **bored**.*

如果说成 ✗ *I am **boring**.*，意思就变成了"我是一个无趣的人"。

**问题：** 为什么电影用 *boring*，我用 *bored*？

回到第二章：*-ing* 和 *-ed* 分别让你想起什么？

……

- *bore* 是一个动词，意思是"让人厌烦"。
- 电影**让人**厌烦，它是做事的一方，所以用 *-ing*：*boring*（使人厌烦的）。
- 我**被**电影弄得厌烦，我是承受的一方，所以用 *-ed*：*bored*（感到厌烦的）。这和第二章被动语态里的过去分词是同一个形式。

> ***-ing* 形容词描述引起感觉的东西，*-ed* 形容词描述产生感觉的人。**

| 引起感觉的东西（-ing） | 产生感觉的人（-ed） |
|---|---|
| The book is **interesting**. | I'm **interested** in the book. |
| The news is **surprising**. | I was **surprised** by the news. |
| The game was **exciting**. | We were **excited**. |
| The work is **tiring**. | I'm **tired**. |
| The question is **confusing**. | I'm **confused**. |

**中文这边，这种区别常常是模糊的。** "我很无聊"既可以表示"我感到无聊"，也可以表示"我这个人很无聊"，要靠上下文来判断。英语则强迫你必须选择。

所以中国学生常常会说出 ✗ *I'm interesting in music* 或 ✗ *I'm so exciting!*，后一句的意思是"我是一个非常令人兴奋的人"。

## 第 7 步：反例

### 反例 1：英语也有不变形就换身份的词

- *Please **water** the plants.*（*water* 是动词：浇水）
- *I'll **email** you.*（*email* 是动词：发邮件）
- *I **booked** a room.*（*book* 是动词：预订）
- *a **fast** car* / *run **fast***（*fast* 既是形容词，又是副词）

这些词的形状不变，就进入了不同的栏目。这不就和中文一样了吗？

……

不完全一样。请看这些词进入栏目以后：

- *He **emailed** me twice.*（进入动词栏，马上贴上时间标签 *-ed*）
- *I got two **emails**.*（进入宾语栏，马上贴上数量标签 *-s*）

这些词的词根虽然没变，可是一旦进入某个栏目，就**必须贴上那个栏目要求的标签**。它们的身份证不是写在后缀上，而是写在**所贴的标签**上。

中文的"学习"无论进入哪个栏目，都不贴任何标签。

### 反例 2：以 *-ly* 结尾的不一定是副词

- *a **friendly** dog*（友好的狗）
- *a **lovely** day*（美好的一天）
- *a **lonely** man*（孤独的人）
- *a **likely** result*（可能的结果）

这些都是**形容词**。为什么同一个 *-ly*，有时变出副词，有时变出形容词？

……

*-ly* 来自古英语里一个表示"像……的样子"的成分（和今天的 *like* 是同一个来源）。

- 加在**名词**后面：*friend* + *-ly* = "像朋友那样的" → 形容词
- 加在**形容词**后面：*quick* + *-ly* = "以快的样子" → 副词

所以 ✗ *He smiled **friendly**.* 是错误的，*friendly* 是形容词，不能修饰动词。要说 *He smiled **in a friendly way**.*

还有一个相关的陷阱：有些词加了 *-ly*，意思完全变了。

| 不加 -ly | 加了 -ly |
|---|---|
| He works **hard**.（努力地） | He **hardly** works.（几乎不工作） |
| He came **late**.（迟到） | I've been busy **lately**.（最近） |

### 反例 3：*look、taste、feel、sound* 后面接形容词，不接副词

- ✓ *She looks **happy**.* ✗ *She looks happily.*
- ✓ *The food tastes **good**.* ✗ *The food tastes well.*
- ✓ *That sounds **great**.*

动词后面不是应该用副词来修饰吗？

……

回到第一章：*The tiger **is** big.* 里，*big* 描述的是主语 *the tiger*，而 *is* 只是挂标签的工具。

*She looks happy* 是同一种结构。*happy* 描述的是**她**，而不是"看"这个动作。*looks* 的作用和 *is* 差不多，只是加上了"看起来"的意思。

**测试方法：** 把动词换成 *is*，看句子是否仍然成立：

- *She looks happy.* → *She **is** happy.* ✓ → 用形容词

对比一下，当 *look* 表示一个真正的动作时：

- *She looked at me **happily**.*（她高兴地看着我）

这里 *happily* 描述的是"看"这个动作的方式，所以用副词。

### 反例 4：名词直接修饰名词

- *a **stone** wall*（石墙）
- *a **car** door*（车门）
- *an **English** teacher*（英语老师）
- ***apple** juice*（苹果汁）

*stone*、*car*、*apple* 都是名词，可是它们在修饰另一个名词。修饰名词的不是应该是形容词吗？

……

英语允许两个名词组合成一个新名词，这一点和中文完全一样（石墙、车门、苹果汁）。

但是请注意一个关键的细节：

- ✗ *a **shoes** shop* → ✓ *a **shoe** shop*（鞋店）
- ✗ *a **ten-years-old** boy* → ✓ *a **ten-year-old** boy*（一个十岁的男孩）
- 对比：*He is ten **years** old.*

**问题：** 为什么放在前面修饰别的名词时，*shoes* 和 *years* 要去掉复数的 *-s*？

……

回到第三章：数量标签是贴在**一个独立的东西**上的。当 *shoe* 被用来修饰 *shop* 时，它已经不再是坐在栏目里的一个独立的东西，而是成了 *shoe shop* 这个名字的一部分，所以不再贴数量标签。

（也有少数例外，比如 *sports car*、*clothes shop*、*sales department*，这些需要单独记住。）

## 第 8 步：一个词换了身份证，周围的词也要跟着换

这是本章最深的一个发现。

> 他突然离开了。
> 他的突然离开让大家很吃惊。

中文里，"离开"从动词变成了名词，"突然"一点没变，只是前面加了"他的"。

英语呢？

- *He left **suddenly**.*
- ***His sudden departure** surprised everyone.*

**问题：** 第二句里，除了 *left* 变成了 *departure*，还有哪些词也跟着变了？为什么？

……

一共变了三处：

| 第一句 | 第二句 | 为什么 |
|---|---|---|
| *left*（动词） | *departure*（名词） | 要坐进主语栏，需要名词的身份证 |
| *suddenly*（副词） | *sudden*（形容词） | 它原来修饰动词，现在修饰名词，修饰名词的必须是形容词 |
| *he*（主语形式） | *his*（所有形式） | 它原来是动词的搭档，现在是名词的所有者 |

> **在英语里，一个词换了身份证，它周围修饰它、和它搭档的词，也必须跟着换身份证。这是一种连锁反应。**

中文没有这种连锁反应："突然"始终是"突然"，只需要加一个"的"。

更多例子：

| 动词的说法 | 名词的说法 |
|---|---|
| We discussed the problem **carefully**. | We had a **careful discussion** of the problem. |
| The economy is **developing rapidly**. | the **rapid development** of the economy |
| He **arrived** **late**. | his **late arrival** |
| They **decided** **wisely**. | their **wise decision** |

### 两种语言的偏好

你也许注意到了，中文更习惯用动词来表达（他突然离开、经济快速发展），英语——尤其是正式的书面英语——更习惯把动作变成名词（*his sudden departure*、*the rapid development*）。

这是一种普遍的倾向：**中文偏爱动词，句子显得动态；书面英语偏爱名词，句子显得静态。** 所以，把中文翻成正式的英语时，常常需要把中文的动词变成英语的名词，然后让整个连锁反应跟着发生。

## 第 9 步：形容词和副词的第三张标签——比较

名词有数量和身份两张标签，动词有时间和人称两张标签。形容词和副词也有自己的标签：**比较**。

> 他高。他比我高。他是我们班最高的。

中文的"高"一个字不变，比较靠前面加"比""更""最"。英语则是直接在词上贴标签：

| 原级 | 比较级 | 最高级 |
|---|---|---|
| tall | tall**er** | tall**est** |
| fast | fast**er** | fast**est** |
| big | big**ger** | big**gest** |
| happy | happ**ier** | happ**iest** |
| easy | eas**ier** | eas**iest** |
| beautiful | **more** beautiful | **most** beautiful |
| interesting | **more** interesting | **most** interesting |
| carefully | **more** carefully | **most** carefully |

**问题：** 为什么有的词直接贴标签（*taller*），有的词却要借助 *more*（*more beautiful*）？

……

和第一章的 *big* 不能贴 *-ed*、要请 *be* 来挂标签，是同一个道理：**短的词能把标签贴在自己身上；太长的词贴不下，英语就请一个小词来帮忙，** 这个小词就是 *more / most*。

粗略的分界线：
- 一个音节的词：直接贴（*tall、fast、old、cheap*）。
- 两个音节、以 *-y* 结尾的词：直接贴，*y* 变 *i*（*happy→happier、easy→easier*）。
- 其他两个音节及以上的词：用 *more / most*（*careful、modern、famous、expensive、difficult*）。

少数不规则的，要单独记：

| 原级 | 比较级 | 最高级 |
|---|---|---|
| good / well | better | best |
| bad / badly | worse | worst |
| many / much | more | most |
| little | less | least |
| far | farther / further | farthest / furthest |

### 比较的句子怎么搭

中文把比较的对象放在形容词**前面**，英语放在**后面**，用 *than* 挂标签。这和第二章、第五章反复出现的"中文往前放，英语往后放"是同一个规律：

| 中文：[比 + 对象] + 形容词 | 英语：形容词 + [than + 对象] |
|---|---|
| 他**比我**高。 | He is taller **than me**. / He is taller **than I am**. |
| 今天**比昨天**冷。 | Today is colder **than yesterday**. |
| 这本书**比那本**有意思。 | This book is more interesting **than that one**. |
| 她跑得**比我**快。 | She runs faster **than me**. |
| 他说得**比我**流利。 | He speaks more fluently **than I do**. |

其他常用的比较结构：

| 中文 | 英语 |
|---|---|
| 和……一样高 | as tall **as** ... |
| 不如……高 | not as / so tall **as** ... |
| 是……的两倍大 | twice **as big as** ... / twice the size of ... |
| 越……越…… | **The more** you practice, **the better** you get. |
| 最高的一个 | **the tallest** (one) |
| 我们班最高的学生 | the tallest student **in** our class |
| 三个人中最高的 | the tallest **of** the three |
| 最好的学生之一 | **one of the** best students（后面是**复数**） |

**最高级前面为什么有 *the*？** 回到第三章：最高级描述的是"唯一的那一个"，听话人一定知道是哪个，所以身份标签是 *the*。

### 比较的四个高频错误

| 错句 | 为什么错 | 正确说法 |
|---|---|---|
| ✗ He is more taller than me. | 比较标签贴了两次（*more* + *-er*） | He is **taller** than me. |
| ✗ She is the most smartest girl. | 同上 | She is the **smartest** girl. |
| ✗ He is very taller than me. | *very* 修饰的是原级；比较级前用 *much、a lot、far、even、still* | He is **much** taller than me. |
| ✗ This is more better. | 同上（*better* 已经是比较级） | This is **better**. |
| ✗ The population of Beijing is larger than Shanghai. | 比较的是"人口"和"上海"，两边不是同类 | The population of Beijing is larger than **that of** Shanghai. |
| ✗ The weather here is better than Beijing. | 同上 | The weather here is better than **in** Beijing. / ... than **that in** Beijing. |

最后两行，中文常常可以省略（"这儿的天气比北京好"），英语却要求比较的两边是**同一类东西**。*that of / those of* 里的 *that / those* 代替前面的名词（*the population*），避免重复。

### 反例：*-ed* 或 *-ing* 形容词、不可比较的词

- ✗ *more unique*、✗ *more perfect*、✗ *very dead*：*unique*（独一无二的）、*perfect*（完美的）、*dead*（死的）本身没有程度，所以不能比较。（口语里有人说 *more perfect*，但仍被认为不规范。）
- ✓ *more tired / more interested / more surprising*：由动词变来的形容词（第 6 步），长，所以用 *more*。

## 第 10 步：副词放在哪里？

副词不贴标签，但它们**有固定的位置**。位置错了，句子就很别扭，有时甚至改变意思。

### 先看一个典型错误

> 我很喜欢音乐。

- ✗ *I like very much music.*
- ✓ *I like music very much.* / *I really like music.*

**问题：** 为什么 *very much* 不能放在 *like* 和 *music* 中间？

……

回到第二章：**英语靠位置决定角色**，动词后面紧跟着的那个位置是宾语栏。如果在动词和宾语中间塞进别的词，会把动词和它的宾语隔开。所以英语的规矩是：

> **动词和宾语要紧挨着。副词要么放在整个"动词 + 宾语"的前面，要么放在它们的后面，不能插在中间。**

中文没有这个限制，副词放在动词前面，宾语在动词后面："我**很**喜欢音乐"。

- ✗ *He speaks fluently English.* → ✓ *He speaks English **fluently**.*
- ✗ *She eats quickly lunch.* → ✓ *She eats lunch **quickly**.*
- ✗ *I can play well the piano.* → ✓ *I can play the piano **well**.*

### 三个固定的位置

| 位置 | 放什么副词 | 例子 |
|---|---|---|
| **句首** | 修饰整个句子：时间、态度 | **Yesterday**, I met him. / **Unfortunately**, he missed the train. |
| **中间**（第一个零件的后面，主要动词的前面） | 频度、程度、"已经、只、也、还" | I **always** get up early. / He **never** lies. / She is **often** late. / I have **already** eaten. / She can **hardly** believe it. |
| **句末** | 方式、地点、时间 | He runs **fast**. / She lives **in Beijing**. / I met him **yesterday**. |

中间这个位置，用的正好是第四章、第八章讲的**第一个零件**：

- 没有零件：副词放在主要动词**前面**：*I **always** get up early.*
- 有零件：副词放在第一个零件**后面**：*I have **always** liked it.* / *She will **probably** come.* / *He can **never** forget it.*
- *be* 是挂标签的零件：副词放在 *be* **后面**：*He **is** always late.* / *She **was** never there.*

### 句末的顺序：方式 → 地点 → 时间

> 我昨天在图书馆安静地看书。

中文的顺序是：**时间 → 地点 → 方式 → 动词**，英语的顺序刚好相反：**动词 → 方式 → 地点 → 时间**。

> *I read **quietly** **in the library** **yesterday**.*

| 中文（时间 → 地点 → 方式 → 动词） | 英语（动词 → 方式 → 地点 → 时间） |
|---|---|
| 他每天早上在公园里跑步。 | He runs **in the park every morning**. |
| 我们昨晚高兴地在餐厅吃了饭。 | We ate **happily at the restaurant last night**. |
| 她明天坐火车去上海。 | She is going **to Shanghai by train tomorrow**. |
| 孩子们安静地在教室里写作业。 | The children did their homework **quietly in the classroom**. |

英语里**时间也可以提到句首**（强调时间背景，用逗号隔开）：*Yesterday, I read quietly in the library.* 这也是第九章讲到的"已知的放前面"。

### 容易搞混的几个副词

| 中文 | 英语 | 位置和用法 |
|---|---|---|
| 也 | *too*（句末，肯定）／*either*（句末，否定）／*also*（中间） | I like it **too**. / I **also** like it. / I don't like it **either**. ✗ *I don't like it too.* |
| 已经 | *already* | 中间或句末：I have **already** eaten. / I have eaten **already**. |
| 还没 | *not ... yet* | 句末：I haven't eaten **yet**. |
| 还（仍然） | *still* | 肯定句放在第一个零件后面：She is **still** sleeping. / She **still** lives here。否定句放在否定的零件前面：He **still** hasn't called.（他还没打电话来） |
| 够 | *enough* | 修饰形容词时放**后面**：tall **enough**；修饰名词时放前面：**enough** money。中文的"够高"放前面。 |
| 太 | *too* | 放形容词**前面**：**too** cold。注意区别：*too*（过分，不好）和 *very*（很）：It's very cold, but I can go out. / It's too cold. I can't go out. |
| 非常／很 | *very* / *really* | 修饰形容词、副词：*very* happy；修饰动词：*really like*、*like ... very much* |
| 只 | *only* | 放在被限定的词的前面：I **only** bought one book.（我只买了一本）和 *I bought **only** one book.* 意思略有不同，位置不同强调的内容不同。 |

### 反例：位置变了，意思也变了

- *He **only** reads novels on Sundays.*（他在周日只读小说，不干别的）
- *He reads **only** novels on Sundays.*（他在周日只读小说，不读别的书）
- *He reads novels **only** on Sundays.*（他只在周日读小说，别的日子不读）

*only* 放在哪个词前面，就限定哪个词，这是英语靠位置决定意思的又一个例子。中文则用"只……才……"这样的固定搭配来区分。

## 第 11 步：用本章原理诊断常见错误

| 错句 | 问题出在哪 | 正确说法 |
|---|---|---|
| ✗ He is very success. | *be* 后面需要形容词 | He is very **successful**. |
| ✗ It's very convenience. | 同上 | It's very **convenient**. |
| ✗ My hometown is very beauty. | 同上 | My hometown is very **beautiful**. |
| ✗ The develop of China is fast. | 主语栏需要名词 | The **development** of China is rapid. |
| ✗ I very like it. | *very* 只能修饰形容词和副词，不能修饰动词 | I **really** like it. / I like it **very much**. |
| ✗ He speaks English very good. | 修饰动作需要副词 | He speaks English very **well**. |
| ✗ She is a beautifully girl. | 修饰名词需要形容词 | She is a **beautiful** girl. |
| ✗ Learn English is important. | 主语栏需要名词性的东西 | **Learning** English is important. |
| ✗ I look forward to see you. | 这个 *to* 是介词 | I look forward to **seeing** you. |
| ✗ I'm interesting in music. | 我是产生兴趣的人 | I'm **interested** in music. |
| ✗ I'm worry about you. | *worry* 是动词 | I'm **worried** about you. / I **worry** about you. |
| ✗ He has been died for 3 years. | *die* 是瞬间动作，持续的状态要用形容词 | He has been **dead** for 3 years. / He **died** 3 years ago. |
| ✗ The food tastes well. | 描述的是食物，需要形容词 | The food tastes **good**. |
| ✗ a ten-years-old boy | 修饰名词时去掉数量标签 | a **ten-year-old** boy |

第五行特别值得想一想：中国学生为什么会说 ✗ *I very like it*？因为中文的"很"既可以修饰形容词（很好），也可以修饰动词（很喜欢）。英语的 *very* 身份证上写的却是"只修饰形容词和副词"。

## 本章总结

```
词的身份证 = 它能贴哪些标签、能进入哪些栏目

  名词：能贴数量、身份标签        → 主语栏、宾语栏、介词后面
  动词：能贴时间、人称标签        → 动词栏
  形容词：能贴比较标签            → 修饰名词、放在 be（或 look 等）后面
  副词：基本不贴标签              → 修饰动词、形容词、整句

英语：
  每个栏目都查身份证，身份证不对就先变形
  变形工具：后缀（-tion, -ness, -ful, -ly ...）
           或者不变词根，直接贴上栏目的标签（email → emailed / emails）
  动词要进入名词的位置：变成 -ing
  一个词换身份证，周围的词跟着换（连锁反应）

中文：
  词的形状不变，可以进入多个栏目
  用"的、地、得"等连接字在旁边标记，而且常常可以省略
  没有连锁反应
```

### 新增的自检步骤

每写一个英语句子，检查每个词：

1. **它在哪个栏目里？** 主语栏、动词栏、修饰名词，还是修饰动作？
2. **它的身份证对吗？** 需要名词时用了名词吗？需要副词时用了副词吗？
3. **有没有发生连锁反应？** 如果一个词换了身份证，修饰它的词是不是也换了？
4. ***-ing* 还是 *-ed*？** 描述的是引起感觉的东西，还是产生感觉的人？

### 和传统语法的对照

| 我们推出来的说法 | 传统语法的叫法 |
|---|---|
| 身份证 | 词性 |
| 能贴数量和身份标签的词 / 能贴时间和人称标签的词 | 名词 / 动词 |
| 修饰名词的词 / 修饰动作的词 | 形容词 / 副词 |
| 换身份证的后缀 | 派生词缀 |
| 不变形就换身份 | 转化（零派生） |
| 拿到名词身份证的 -ing | 动名词 |
| *look、taste、feel* 后面接形容词 | 系动词 + 表语 |
| 名词修饰名词 | 名词作定语 |
| 动作变成名词 | 名词化 |
| 中文一个词进入多个栏目 | 兼类 / 词类活用 |

## 例句库（多看几组）

**一、词族：同一个词根，在不同的栏目里**

| 动词 | 名词 | 形容词 | 副词 |
|---|---|---|---|
| decide | decision | decisive | decisively |
| succeed | success | successful | successfully |
| differ | difference | different | differently |
| depend | dependence | dependent | — |
| act | action / actor | active | actively |
| produce | production / product | productive | productively |
| create | creation / creativity | creative | creatively |
| apply | application / applicant | applicable | — |
| employ | employment / employee | employed | — |
| — | beauty | beautiful | beautifully |
| — | danger | dangerous | dangerously |
| — | care | careful / careless | carefully / carelessly |
| — | quickness | quick | quickly |
| — | happiness | happy | happily |

句子里的变化：

- 他**决定**了。→ He **decided**. （动词）
- 他的**决定**很明智。→ His **decision** was wise. （名词）
- 他是个很**果断**的人。→ He is a very **decisive** person. （形容词）
- 他**果断地**行动了。→ He acted **decisively**. （副词）

**二、容易搞混的"形容词 / 副词"对子**

| 形容词 | 副词 | 例句 |
|---|---|---|
| good | well | He is a **good** singer. / He sings **well**. |
| fast | fast | a **fast** car / He drives **fast**. （同形） |
| hard（难的、硬的） | hard（努力地）／hardly（几乎不） | It's a **hard** job. / He works **hard**. / He **hardly** works. |
| late（晚的） | late（晚地）／lately（最近） | a **late** train / He came **late**. / I haven't seen him **lately**. |
| early | early | an **early** bird / He gets up **early**. （同形） |
| high | high（高地）／highly（高度地） | a **high** wall / He jumped **high**. / a **highly** paid job |
| near | near / nearly（几乎） | the **near** future / He lives **near** here. / It's **nearly** midnight. |
| free | free（免费地）／freely（自由地） | **free** tickets / Kids eat **free**. / Speak **freely**. |

**三、-ing / -ed 形容词，多看几个**

| 引起感觉的东西（-ing） | 产生感觉的人（-ed） |
|---|---|
| The movie is **disappointing**. | I'm **disappointed**. |
| That's **embarrassing**. | I feel **embarrassed**. |
| This is **frightening**. | The child was **frightened**. |
| It's a **relaxing** place. | I feel **relaxed**. |
| What a **shocking** result! | We were **shocked**. |
| The lesson was **boring**. | The students were **bored**. |
| It's a **worrying** sign. | She is **worried**. |

**四、一个词换了身份，周围的词要跟着换（更多）**

| 动词的说法 | 名词的说法 |
|---|---|
| They **discussed** the plan **seriously**. | They had a **serious discussion** of the plan. |
| He **responded quickly**. | His **quick response** surprised us. |
| She **speaks** English **fluently**. | Her **fluent** English impressed everyone. |
| The company **expanded rapidly**. | The company's **rapid expansion** ... |
| He **behaves badly**. | His **bad behavior** ... |
| They **argued loudly**. | Their **loud argument** woke us up. |

## 通往第八章

到这里，英语句子的零件都齐了：栏目、开关、零件、标签、名词的身份、词的身份证。而且你也许已经注意到，动词栏的**第一个零件**一次又一次地扮演着特殊的角色：第一章里，*do* 在否定和疑问时出来挂标签；第四章里，标签只贴在第一个零件上；第六章里，情态动词作为第一个零件，自己负责否定和疑问。

前七章几乎只用陈述句。可是人说话时还要提问、要否定：中文只在句末加个"吗"、在动词前加个"不"，英语却要把一个零件挪到主语前面，还要请出 *do*。这些变化全都围绕着第一个零件。为什么？这是第八章的问题。
