# 第三章：中文说"书"，英语为什么非要说清是哪本、几本？

## 第 0 步：回顾

到目前为止，英语句子的表格是这样的：

```
【主语栏】    【动词栏】          【宾语栏】      【挂标签的成员】
 做事的一方    贴好标签的开关      承受的一方       to / with / in ...
（或挂了被动   （贴不上就请 be）
 牌子的承受者）
```

第一章发现，**动词**放进动词栏时身上必须贴两张标签：时间和人称。第二章发现，每个参与者都要靠位置或标签说明自己的角色。

这一章要讨论的是：**名词**放进主语栏或宾语栏时，是不是也有必须贴的标签？

---

## 第 1 步：问题出现了

> 我昨天买了书。

**问题：** 买了几本？是哪本书？

……

中文完全不在乎这两个问题。你可能买了一本，也可能买了五本；可能是朋友推荐的那本，也可能是随手拿的一本。"书"这个字什么都不告诉你，而听的人也不觉得缺了什么。

现在翻成英语，你会发现**根本没办法只说"书"**，必须做出选择：

- *I bought **a book**.*（买了一本，你不知道是哪本）
- *I bought **some books**.*（买了几本）
- *I bought **the book**.*（买了那本书，你知道是哪本）
- *I bought **the books**.*（买了那几本书，你知道是哪几本）

✗ *I bought book.* 这样说是不行的。

**结论：英语的名词进入表格时，也必须贴标签。** 下面一张一张来看。

---

## 第 2 步：名词的第一张标签——数量

**问题：** 中文怎样表达"一"和"多"？

……

中文当然能表达数量："一本书""三本书""很多书"。可是请注意，**"书"这个字本身从来不变**。数量靠数词和量词来表达，而且只在需要时才说。

英语则是**名词自己变形**：

| 中文 | 英语 |
|---|---|
| 一本书 | a book |
| 三本书 | three book**s** |
| 我喜欢猫。 | I like cat**s**. |
| 桌上有书。 | There **is** a book / There **are** books on the table. |
| 他是学生。 | He is **a** student. |
| 他们是学生。 | They are student**s**. |

和动词一样，这张标签**不管你需不需要，都必须贴**。

注意倒数第三行："桌上有书"翻成英语时，不仅名词要选单数或复数，连动词 *is / are* 也要跟着变。这就是第一章的**人称契约**：名词贴了什么数量标签，和它签约的动词就要贴相应的人称标签。名词的标签和动词的标签是**联动**的，选错一个，另一个也跟着错。

---

## 第 3 步：英语里也有"需要量词"的名词

**问题：** 下面这些词能加 *-s* 吗？

*water, rice, money, information, advice, furniture, homework*

……

都不能。✗ *waters* ✗ *informations* ✗ *advices* ✗ *furnitures* ✗ *homeworks*

为什么？我们来做一个思想实验：

> 把**一本书**撕成两半，你手里的还是"一本书"吗？
> 把**一杯水**倒掉一半，剩下的还是"水"吗？

……

半本书已经不算一本书了；半杯水仍然是水。

于是英语把名词分成两类：

- **有边界的个体**：切开以后就不再是原来的东西，可以一个一个地数。（传统语法称为**可数名词**）
- **没有边界的一团**：切开以后还是原来的东西，没法一个一个地数。（传统语法称为**不可数名词**）

### 关键的发现：中文的所有名词都像"一团"

这一点对中文母语者理解英语特别重要。

中文**不能**说"三书""五猫"，必须说"三**本**书""五**只**猫"。也就是说，**在中文语法里，每个名词都被当作没有边界的一团，需要量词把它切成一个个单位才能计数。**

而英语的可数名词**本身就是切好的**，可以直接加数字：*three books*。

英语的不可数名词则和中文名词一样，**需要量词**：

| 中文 | 英语的不可数名词也要"量词" |
|---|---|
| 一**件**家具 | a **piece of** furniture |
| 一**条**信息 | a **piece of** information |
| 一**条**建议 | a **piece of** advice |
| 一**杯**水 | a **glass of** water |
| 一**粒**米 | a **grain of** rice |
| 一**块**面包 | a **slice of** bread |

所以你可以这样理解：**英语的不可数名词，就是英语里像中文名词一样需要量词的那一类。** 这样一来，它就不再是一条陌生的规则，而是你本来就熟悉的东西。

### 反例 1：同一个词，有时可数，有时不可数

| 有边界（可数） | 没有边界（不可数） |
|---|---|
| **a** chicken（一只鸡） | chicken（鸡肉） |
| **a** paper（一份报纸、一篇论文） | paper（纸） |
| **a** glass（一个玻璃杯） | glass（玻璃） |
| **a** coffee（一杯咖啡，在咖啡馆点单时） | coffee（咖啡这种饮料） |
| **an** experience（一次经历） | experience（经验） |
| **a** hair（一根头发） | hair（头发的总体） |

**问题：** 这不是自相矛盾吗？

……

不矛盾。这恰好说明**可数与不可数并不是事物本身的属性，而是说话人看待它的方式**：你把它当作一个一个的个体，还是当作一团。一只活鸡是一个完整的个体，鸡肉是一团可以随意切分的物质。

中文也在做同样的区分，只是用的是**不同的词**或**不同的量词**："一只鸡"和"一块鸡肉"。

### 反例 2：意思一样，标签却不一样

- *a suggestion*（可数）和 *advice*（不可数）都是"建议"。
- *a chair*（可数）属于 *furniture*（不可数）。

**问题：** 椅子明明可以一把一把地数，为什么 *furniture* 不可数？

……

因为 *furniture* 说的是"家具"这一**整个类别**，而类别本身并没有一个一个的边界。*suggestion* 和 *advice* 的情况则说明，**同一个意思，不同的词可以有不同的包装方式**。

坦白地说，这一部分有一定的随意性，没有办法完全推导出来，需要查词典。词典会用 **C**（可数）和 **U**（不可数）来标注。中国学生最常出错的不可数名词有：

> *information, advice, furniture, homework, news, luggage, equipment, research, evidence, knowledge*

### 反例 3：只能用复数形式的名词

*scissors*（剪刀）、*trousers*（裤子）、*glasses*（眼镜）

这些东西都由两个对称的部分组成，所以英语总是用复数形式来称呼它们。要数的时候说：*a pair of scissors*（一把剪刀）。

---

### 补充：数量词——"很多""一点""几个"，英语要先问一句"能数吗"

中文的"很多""一些""一点""几个"，对任何名词都通用："很多书""很多水""很多人"。英语却要先看那个名词是**个体**还是**一团**，再选数量词：

| 中文 | 个体（可数复数） | 一团（不可数） |
|---|---|---|
| 很多 | **many** books | **much** water |
| 很多（口语，两类通用） | **a lot of** books / **lots of** books | **a lot of** water |
| 一些 | **some** books | **some** water |
| 有几个／有一点（肯定） | **a few** books | **a little** water |
| 没几个／没多少（几乎没有） | **few** books | **little** water |
| 没有 | **no** books | **no** water |
| 更多 | **more** books | **more** water |
| 更少 | **fewer** books | **less** water |
| 足够 | **enough** books | **enough** water |
| 所有 | **all** the books | **all** the water |
| 每一个 | **every / each** book（单数！） | — |

这张表可以直接推出来：**能数的才能用 *many*、*few*、*fewer*，不能数的才用 *much*、*little*、*less*。** *a lot of* 是个万能的选择，所以口语里用得最多。

*many / much* 在肯定句里常常显得生硬，更自然的是 *a lot of*；在否定句和疑问句里才大量使用：

- ✓ *I have **a lot of** friends.* （肯定句）
- ✓ *I don't have **many** friends.* / ***How many** friends do you have?*（否定、疑问）
- ✓ *He doesn't have **much** money.* / ***How much** money does he have?*

**问题：** *few* 和 *a few* 差在一个 *a*，意思为什么相反？

……

- *I have **a few** friends here.*（我在这儿有几个朋友。肯定了"有"）
- *I have **few** friends here.*（我在这儿几乎没有朋友。强调"没有多少"）

可以这样理解：*a few* 里的 *a* 把"几个"当作一份**存在的东西**拿出来，说话人的重点是"有"；没有 *a*，就只剩下"数量少"这个量，重点变成了"不够"。*little* 和 *a little* 同理：

- *There is **a little** milk left.*（还剩一点牛奶，够用）
- *There is **little** milk left.*（几乎没剩牛奶了，不够）

中文用的是不同的词来区分："有几个""有一点"和"没几个""没多少"。

**every / each 后面接单数**，这是第一章的人称契约又一次出场：

- ✓ ***Every** student **has** a book.* ✗ *Every students have books.*
- ✓ ***Each** of the students **has** a book.*（*each of* 后面是复数名词，动词仍然配 *each*，是单数）

**some / any**（第八章会再见到 *any*）：

- ✓ *I have **some** questions.*（肯定）
- ✓ *Do you have **any** questions?*（疑问）
- ✓ *I don't have **any** questions.*（否定）
- ✓ *Would you like **some** tea?*（疑问句里用 *some*，是因为说话人期待对方说"好"，把它当作一件有可能成立的事）

## 第 4 步：名词的第二张标签——"你知道是哪一个吗？"

> 我昨天买了一本书。书很有意思。

**问题：** 第二句里的"书"指的是哪本书？中文用了什么手段告诉你？

……

指的是昨天买的那本。中文什么手段都没用，靠上下文就够了。

英语必须明确标出来：

> *I bought **a** book yesterday. **The** book is very interesting.*

第一次提到时用 *a*，第二次提到时用 *the*。

**问题：** *a* 和 *the* 的区别到底是什么？

提示：想一想，这个区别取决于**说话的人**，还是取决于**听话的人**？

……

> ***the*** **表示："你知道我说的是哪一个。"**
> ***a*** **表示："某一个，你不知道或者不需要知道是哪一个。"**

关键在于**听话人知不知道**。说话人自己当然知道买的是哪本书，可是第一次提到时，听话人还不知道，所以用 *a*。

这又回到了第一章的起点：语言是用来把我脑子里的东西搬到你脑子里的。用 *a* 还是 *the*，取决于**这个东西是否已经在你的脑子里了**。

### 听话人怎么会知道是哪一个？

| 原因 | 例句 |
|---|---|
| 前面已经提到过 | I saw a dog. **The** dog was huge. |
| 就在眼前 | Close **the** door. / Pass me **the** salt. |
| 大家都知道，只有一个 | **the** sun, **the** moon, **the** internet |
| 后面的话说明了是哪一个 | **the** book on the table / **the** man who called you |
| 本身就是唯一的 | **the** best, **the** first, **the** only, **the** same |

---

## 第 5 步：中文怎样表达"你知道是哪一个"？

中文也有表达"那一个"的手段，比如"这""那"："**那**本书很有意思"。但中文不是每次都用。那么在不用"这""那"的时候，中文靠什么？

**问题：** 下面两句话有什么区别？

> 客人来了。
> 来客人了。

……

"**客人来了**"：这些客人是你们早就知道要来的，比如约好来吃饭的人。
"**来客人了**"：来了一些客人，你们事先不知道。

翻成英语：

- 客人来了。→ ***The** guests have arrived.*
- 来客人了。→ *We have **some** visitors.* / *There are **some** guests here.*

这是一个重要的发现：

> **中文也在区分"你知道的"和"你不知道的"，但它用的是位置，而不是标签。**
> 放在动词前面的，倾向于是你知道的；放在动词后面的，倾向于是新出现的。

再看几组：

| 中文 | 英语 |
|---|---|
| **书**我放桌上了。（你知道是哪本） | I put **the** book on the table. |
| 桌上有**一本书**。（新出现的） | There's **a** book on the table. |
| **信**收到了。（你知道是哪封） | I got **the** letter. |
| 我收到了**一封信**。（新出现的） | I got **a** letter. |

## 第 6 步：第三种情况——说的是一整类

> 我喜欢猫。

**问题：** 这里说的是哪只猫？

……

不是哪一只猫，而是**猫这一整类动物**。

英语怎么说？

- ✓ *I like **cats**.*（复数，不加冠词）
- ✗ *I like cat.*
- *I like **the** cats.* → 意思变成了"我喜欢这几只猫"，是特定的猫

对于不可数名词，说一整类时连复数都不需要，直接用原形：

- 我喜欢音乐。→ *I like **music**.*
- 水很重要。→ ***Water** is important.*
- 生活很难。→ ***Life** is hard.*

中国学生常犯的错误是在这里加上 *the*：✗ *I like the music.*（如果你想表达的是一般意义上的音乐）、✗ *The life is hard.*。*the* 会把"一整类"变成"特定的那个"。

---

## 第 7 步：把两张标签合起来

名词的两张标签可以组合成下面这张表：

| | 可数单数 | 可数复数 | 不可数 |
|---|---|---|---|
| **你知道是哪个** | the book | the books | the water |
| **某个，你不知道是哪个** | a book | (some) books | (some) water |
| **整类** | — | books | water |

请注意表格里那个**空缺**的地方：可数单数名词**从来不能不加任何东西就单独出现**。

> **本章核心定律：可数名词的单数形式，绝不能"光着"出现。** 它前面必须有一个词来说明它的身份：*a*、*the*、*my*、*this*、*every* 等等。

- ✗ *I have **book**.* → *I have **a** book.*
- ✗ *She is **teacher**.* → *She is **a** teacher.*
- ✗ *I bought **car**.* → *I bought **a** car.*

### 为什么会有这条定律？

看表格最后一列：不可数名词是可以"光着"出现的（*I like water*）。也就是说，**"光着的单数形式"这个位置已经被"没有边界的一团"占用了**。

如果一个可数名词光着出现，英语母语者就会把它理解成"一团物质"。

最有名的例子：

- *I like **chickens**.* → 我喜欢鸡（这种动物）
- *I like **chicken**.* → 我喜欢吃鸡肉
- *I like **dog**.* → 可能被理解为"我喜欢吃狗肉"

所以，可数名词必须加上 *a* 或 *the*，或者变成复数，才能保持"一个一个的个体"这个身份。

---

### 补充：身份标签只有一个座位

中文可以把好几个限定的词叠在一起：

> 我的这三本书、他的那几个朋友、你们的每一个孩子

英语的身份标签（*a、the、my、this、some、every、no……*）却**只有一个座位**，坐了一个，其他的就得换一种说法：

| 错句 | 为什么错 | 正确说法 |
|---|---|---|
| ✗ *my the book* | *my* 和 *the* 抢一个座位 | *my book* |
| ✗ *a my friend* | *a* 和 *my* 抢一个座位 | *a friend of mine* / *one of my friends* |
| ✗ *this my book* | 同上 | *this book of mine* |
| ✗ *the this book* | 同上 | *this book* |
| ✗ *some the books* | 同上 | *some of the books* |
| ✗ *the my sister's husband* | 同上 | *my sister's husband* |

**反例：** 为什么 *all the books*、*both my parents*、*half the time* 可以叠起来？

……

*all、both、half* 说的是"一整套里的多少"，它们是**站在座位前面的**，管的是整个集合的范围，所以可以出现在 *the / my* 的前面：*all the students*、*both my parents*、*half the cake*。数字则站在座位后面：*the **three** books*、*my **two** sisters*。

顺序是：**范围词（all, both, half）→ 座位（the, my, this）→ 数字 → 形容词 → 名词**。

> *all the big red apples*（范围 → 座位 → 形容词 → 名词）
> *the three big red apples*（座位 → 数字 → 形容词 → 名词）

**所有格：谁的？**

英语的"我的、你的、他的"（*my、your、his、her、its、our、their*）也占这个座位，所以：

- 中文："我的书"、"这是我的"。英语：*my book*、*This is **mine**.*（单独用时，要变成 *mine / yours / his / hers / ours / theirs*，因为后面没有名词可以让座位挂靠了）
- 名词的所有格用 *'s*：*my sister**'s** husband*、*the children**'s** toys*；没有生命的东西用 *of*：*the door **of** the room*、*the end **of** the story*。

**中文常常省掉的"我的"，英语必须说出来。** 这又是"中文按需、英语强制"：

| 中文（不说"谁的"） | 英语（座位上必须有人） |
|---|---|
| 他举起手。 | He raised **his** hand. |
| 我洗了手。 | I washed **my** hands. |
| 我给妈妈打了电话。 | I called **my** mother. |
| 她点点头。 | She nodded **her** head. |
| 他丢了钱包。 | He lost **his** wallet. |
| 我头疼。 | I have a headache. / **My** head hurts. |

**指示词要跟着数量变：** *this book → these books*，*that book → those books*。中文的"这、那"不用变，所以 ✗ *this books*、✗ *those book* 是中国学生的常见错误。

**one / ones：** 为了不重复说名词，可以用 *one*（单数）或 *ones*（复数）代替：*I like the red **one**.* / *Which **ones** do you want?*。注意，*one / ones* 代替的是**可数**名词；不可数名词不用 *one*，直接省略：*I prefer red wine to white.*

## 第 8 步：核心定律的反例

### 反例 1：go to school、go to bed、by bus

- *go to **school***（去上学）
- *go to **bed***（上床睡觉）
- *at **home***（在家）
- *have **breakfast***（吃早饭）
- *by **bus*** / *by **car***（坐公交车、开车）
- *at **night***（在夜里）

这些可数名词都是光着出现的。为什么？

请比较：

- *go to **school*** = 去上学（一种活动）
- *go to **the** school* = 去那所学校（比如家长去开家长会，去的是那栋建筑）

……

光着出现时，这些名词**不再表示一个具体的个体，而是表示一种功能或活动**。*by bus* 说的是交通方式，而不是某一辆具体的公交车。功能和活动没有一个一个的边界，所以可以光着用，这和不可数名词的道理一样。

中文其实也有类似的区分："**上学**"和"**去学校**"。

（*in hospital* 表示住院，这是英式用法；美式英语一般说 *in **the** hospital*。）

### 反例 2：职位和身份

- *He was elected **president**.*（他当选为总统）
- *She became **captain** of the team.*（她当上了队长）

这里说的也不是一个具体的人，而是一个**角色**。角色和功能一样，可以光着用。

### 反例 3：人名和地名

*John, Beijing, China* 都不加冠词。因为名字本身就已经说明了是哪一个，第二张标签已经包含在名字里了。

那为什么 ***the** United States*、***the** Great Wall*、***the** Yangtze River*、***the** Pacific* 要加 *the*？

……

前两个名字是由普通名词构成的："联合的那些**州**"、"那道伟大的**墙**"。名字里面藏着普通名词，所以保留了 *the*。至于河流、海洋要加 *the*，这主要是一种惯例，只能记住。

### 反例 4：不可数名词前面加了 a

- *We had **a** good **time**.*（我们玩得很开心）
- *This is **a** very good **wine**.*

*time* 和 *wine* 本来不可数，为什么能加 *a*？

……

因为形容词把它**切出了有边界的一块**：一段愉快的经历、一种好酒。一旦有了边界，就可以加 *a*。

## 第 9 步：已知的放前面，新出现的放后面

第一章第 4 步的反例 3 里，我们见过 *There is a book*。当时只解释了 *there* 是占位符、当不了动词的搭档，却没有回答一个更根本的问题：**英语为什么要多此一举，先放一个空壳 *there*？** 另外，中国学生还常常照着"这里有一本书"说出 ✗ *Here has a book*，这又错在哪里？

学完本章的 *a* 和 *the*，这两个问题都可以回答了。先看一个更直接的对比：

> ? *A book is on the table.*
> ✓ *There is a book on the table.*

第一句在语法上没错，但英语母语者很少这样说。为什么？

……

第 5 步发现了一个规律：**人们倾向于从已知的东西说起，把新出现的东西放在后面**。中文是这样（"来客人了"），英语其实也是这样。

可是英语有一个麻烦：第一章说过，**主语栏必须填写**。如果新出现的 *a book* 坐进了主语栏，它就被放在了句子开头。

英语的解决办法是：用 *there* 先把主语栏占住，再把新出现的东西放到动词后面。

两种语言的解决办法放在一起对比：

| 中文：用"有""来"把新东西放到动词后面 | 英语：用 *there* 占住主语栏，把新东西放到动词后面 |
|---|---|
| 桌上**有**一本书。 | **There is** a book on the table. |
| 门口**站着**一个人。 | **There is** someone standing at the door. |
| **来**客人了。 | **There are** some guests here. |
| 这里**有**一本书。 | **There is** a book here. |

至于 ✗ *Here has a book*，它的错误在于：*here* 是地点，当不了"有"这个动作的做事者，*have* 的主语栏必须放一个能"拥有"的东西。中文的"这里"是话题，英语的主语栏却不接受话题（第一章第 4 步）。

## 第 10 步：用本章原理诊断常见错误

| 错句 | 问题出在哪 | 正确说法 |
|---|---|---|
| ✗ She is teacher. | 可数单数光着出现 | She is **a** teacher. |
| ✗ I have a lot of homeworks. | *homework* 不可数 | I have a lot of **homework**. |
| ✗ Can you give me some advices? | *advice* 不可数 | some **advice** / some **suggestions** |
| ✗ I like dog. | 可数单数光着，会被理解成狗肉 | I like **dogs**. |
| ✗ I bought a book. A book is great. | 第二次提到时听话人已经知道是哪本 | **The** book is great. |
| ✗ Sun rises in east. | 唯一的东西，人人都知道 | **The** sun rises in **the** east. |
| ✗ I like the music.（想说一般的音乐） | *the* 把整类变成了特定的 | I like **music**. |
| ✗ I go to the bed at 11. | 这里表示的是活动，不是那张床 | I go to **bed** at 11. |
| ✗ There are many peoples. | *people* 本身就是 *person* 的复数 | There are many **people**. |

最后一条还有一个有意思的反例：*peoples* 这个词是存在的，但它的意思是"**民族**"（*the peoples of Asia*，亚洲各民族）。一个民族是一个有边界的个体，所以 *people* 在这个意思上又变成了可数名词。

## 本章总结

```
英语的表格（第三版）：

【主语栏】    【动词栏】     【宾语栏】      【挂标签的成员】
   ↑            ↑              ↑
 名词贴两张    动词贴两张     名词贴两张
  标签          标签           标签

 动词的两张标签：时间（远近）、人称
 名词的两张标签：数量（单数 / 复数 / 一团）
               身份（你知道的那个 / 某一个 / 整类）
```

```
中文：名词不贴标签。
      数量靠数词和量词，需要时才说。
      "你知道的那个"靠位置（放在动词前面）或"这""那"来表达。
```

### 每个名词都问两个问题

1. **它是一个个的个体，还是一团？** 如果是个体，是单数还是复数？
2. **听话人知道我说的是哪一个吗？** 知道就用 *the*；不知道就用 *a*、*some* 或复数；说一整类就用复数或不可数名词的原形。

**最后检查：** 可数名词的单数形式有没有光着出现？

### 和传统语法的对照

| 我们推出来的说法 | 传统语法的叫法 |
|---|---|
| 有边界的个体 / 没有边界的一团 | 可数名词 / 不可数名词 |
| 数量标签 | 名词的单复数 |
| 不可数名词的"量词"（a piece of） | 单位词 |
| 身份标签：你知道的那个 / 某一个 / 整类 | 特指 / 不定指 / 泛指 |
| *the* / *a* / 什么都不加 | 定冠词 / 不定冠词 / 零冠词 |
| 用 *there* 占住主语栏引出新事物 | there be 句型（存现句） |

**一、个体还是一团？再多看一些容易错的名词**

| 一团（不可数，不加 -s，不用 a） | 要数的时候，加"量词" | 对应的个体说法 |
|---|---|---|
| news（消息） | a piece of news | a story / an item |
| advice（建议） | a piece of advice / a word of advice | a suggestion |

| furniture（家具） | a piece of furniture | a chair / a table |
| luggage / baggage（行李） | a piece of luggage | a suitcase / a bag |
| equipment（设备） | a piece of equipment | a machine / a tool |
| weather（天气） | — | — |
| traffic（交通） | — | a car / a vehicle |
| work（工作；作为"事情"） | a piece of work | a job（一份工作）|
| money（钱） | a sum of money | a coin / a note / a dollar |
| progress（进步） | a bit of progress | a step forward |
| research（研究） | a piece of research | a study |

| rain（雨） | a drop of rain | a shower |

例句：

- *The **weather** is nice today.* （✗ *The weather are nice*）
- *The **traffic** was terrible.* （✗ *The traffics were terrible*）
- *She has made great **progress**.* （✗ *a great progress*）
- *I found a **job** last month.* / *I have a lot of **work** to do.*（*job* 是一份份的工作，*work* 是一团事情）
- *Can I give you a **piece of advice**?*

**二、不规则复数：记住几组最常用的**

| 单数 | 复数 | 备注 |
|---|---|---|
| man / woman | men / women | |
| child | children | |
| foot / tooth | feet / teeth | |
| mouse | mice | |
| person | people | *persons* 只用在法律文件里 |
| fish | fish | 种类多时 *fishes* |
| sheep / deer | sheep / deer | 单复数同形 |
| knife / wife / life | knives / wives / lives | f → ves |
| city / baby / country | cities / babies / countries | 辅音 + y → ies |
| bus / box / watch | buses / boxes / watches | 加 -es |
| photo / potato / tomato | photos / potatoes / tomatoes | 有的加 -es，有的加 -s |

**三、不加冠词、加 a、加 the：多看几个对比**

| 中文 | 英语 | 为什么 |
|---|---|---|
| 我弹钢琴。 | I play **the** piano. | 乐器前用 *the*（惯例） |
| 我踢足球。 | I play football. | 球类、游戏前不加冠词（惯例） |
| 她是医生。 | She is **a** doctor. | 可数单数，不能光着 |
| 她们是医生。 | They are doctors. | 复数，可以光着 |
| 我早上喝咖啡。 | I drink coffee in **the** morning. | *coffee* 是一团；*in the morning* 是固定说法 |
| 晚饭我吃了米饭。 | I had rice for dinner. | 一团，加上 *for dinner*（泛指这一餐） |
| 昨晚的晚饭很好吃。 | **The** dinner last night was delicious. | 特指某一顿 |
| 我在上班。 | I'm at work. | 功能、活动，光着 |
| 他住在国外。 | He lives abroad. | *abroad* 是副词，不加冠词、不加介词 |
| 一天两次。 | twice **a** day | *a* 在这里表示"每" |
| 我想买辆车。 | I want to buy **a** car. | 对方还不知道是哪辆 |
| 请把车开过来。 | Please bring **the** car around. | 对方知道是哪辆 |
| 我需要一点帮助。 | I need some help. / I need **a** little help. | *help* 是一团 |
| 春天来了。 | Spring is here. | 季节一般不加冠词 |
| 那年春天我们搬家了。 | We moved that spring. | 特指某一个春天，用 *that* 占座位 |

**四、"谁的"别忘了说**

- ✗ *I lost wallet.* → ✓ *I lost **my** wallet.*
- ✗ *She shook head.* → ✓ *She shook **her** head.*
- ✗ *He brushes teeth twice a day.* → ✓ *He brushes **his** teeth twice a day.*
- ✗ *Open mouth, please.* → ✓ *Open **your** mouth, please.*
