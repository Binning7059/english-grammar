## 这是什么

一套十章的英语语法讲义。它不从"主谓宾定状补""十六种时态"这些术语讲起，而是从一个问题出发：

> **一个英语句子，最少需要什么？**

然后用第一性原理和苏格拉底式追问，一步步推出英语句子是怎么搭起来的。每推出一条规律，都和中文放在一起对照：中文为什么不需要它，英语为什么离不开它。

整套讲义只有一个核心比喻：

| | 中文 | 英语 |
|---|---|---|
| 像什么 | **聊天** | **填表** |
| 靠什么组织句子 | 意思（意合） | 结构（形合） |
| 缺了信息怎么办 | 听的人自己补 | 说的人必须填满 |
| "我很忙" | 我 + 很忙 ✓ | ✗ *I busy* → *I **am** busy* |
| "书" | 不用说是哪本、几本 | 必须选：*a book* / *the book* / *books* |
| "昨天我去了" | 时间词说一次就够 | 动词本身也要变：*I **went*** |

## 先尝一口

第一章是这样开始的：

**第 0 步：唯一的前提**

> 语言的作用，是把我脑子里的一件事，搬进你脑子里。

**第 1 步：一个词什么时候就够了？**

你和朋友在野外，一头老虎从草丛里冲了出来。你大喊一声："Tiger!" 朋友听懂了吗？听懂了，因为**眼前的情境**已经替你说了在哪里、发生了什么。

第二天回到村里，你对没去的人喊："老虎！" 他们听懂了吗？没听懂。老虎来了？老虎死了？情境不在了，缺的信息只能靠语言自己补上。

> 语法，就是情境不在时，用语言把缺的信息补上的那套方法。

接下来的问题是：中文和英语补信息的方式一样吗？

后面每一章都是这样：先提出一个中文母语者真实会遇到的困惑，再一步步推，推完给反例，说明为什么反。

## 这套讲义的特点

- **从问题出发**：每一条规律都先问"为什么"，再推出来，而不是直接给出结论让你背。
- **处处对照中文**：不只讲英语怎么说，还讲中文为什么不这么说，帮你看清两种语言的根本差别。
- **大量反例**：每章都有"反例"小节，收集中文母语者最常说错的句子，并用本章原理解释错在哪里。
- **练习和答案**：每章末尾有练习，答案默认折叠，先做再看。
- **前后贯通**：后一章只用前面推出来的零件，第十章把全部零件装回一个完整模型。

## 适合谁

- 背过很多语法规则，但说话写作时还是会出错的人
- 想知道英语"为什么这样"，而不满足于"就是这样"的人
- 教英语、想换一种讲法的老师

不适合想要考试题型速成技巧的读者：这里讲的是句子的构造原理，不是做题方法。

## 怎么读

1. **按顺序读**。每章从"回顾"开始，到"通往下一章"结束，后面的章节依赖前面推出的概念。
2. **遇到问题先自己想**。文中的追问不是修辞，停下来想一想再往下看，效果完全不同。
3. **做练习**。答案折叠着，做完再点开。
4. **最后读第十章**。它把前九章拼成一张总地图，平时造句、读长句都可以对照使用。
